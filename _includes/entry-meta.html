{% comment %} Entry Meta Component Purpose: Render reusable author and publication metadata for content-entry UI, including cards, post headers, and page headers. Structure: - Component root (c-entry-meta) - Optional avatar wrapper - Author avatar image - Meta content wrapper - Author name - Meta details group - Publish date - Optional read time - Read time icon - Read time text Architecture: - Uses ITCSS + BEM naming - Component block: - c-entry-meta - Designed as a standalone component to be included in: - post-card.html - post.html - page.html - Accepts: - include.entry_meta: post/page object - include.show_avatar: boolean-like flag controlling avatar visibility - include.show_read_time: flag controlling read-time visibility; true when omitted, and only the boolean false hides it Accessibility: - Uses a semantic time element for the publish date - Decorative timer icon is hidden from assistive technology - Avatar alt text falls back to the resolved author name Data dependencies: - include.entry_meta - include.entry_meta.author - include.entry_meta.authors - include.entry_meta.avatar - include.entry_meta.date - include.entry_meta.content - include.entry_meta.read_time_override - include.show_avatar - include.show_read_time - site.data.author.name - site.data.author.avatar - site.read_time - read-time.html include Notes: - This component centralizes metadata markup so cards, posts, and pages share the same structure - A positive read_time_override in an entry's front matter replaces only the minutes shown, rounded to the nearest whole minute; whether the read time appears at all is still decided by show_read_time, site.read_time, and the entry's content. A value that is empty, non-numeric, or rounds to zero or below falls back to the estimate.
